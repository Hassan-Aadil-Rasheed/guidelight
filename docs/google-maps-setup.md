# Nearby search stays inside GuideLight

Version 0.19.1 removes the external Google Maps lookup at the user's request.
GuideLight no longer opens Google Maps from its nearby search screen.

Use a nearby category or enter a place name, tap **Find place**, then choose
a suggestion to start walking directions inside GuideLight. No paid Google
Maps/Places API or billing setup is used. Free provider listings can still
miss local businesses. See [Free nearby search](free-nearby-search.md).
